# Realpolitik

Tarihin krizlerini yönettiğin jeopolitik strateji ve diplomasi simülasyonu.

## Özellikler ve Hikâye Dosyaları

- **Küba Füze Krizi (1962 · Washington – Moskova):** 13 günlük nükleer kriz masası. Kennedy (ABD) veya Kruşçev (SSCB) olarak yönet; abluka, U-2 uçuşları, istihbarat, gizli kanallar ve ExComm danışman kararları.
- **Çanakkale Cephesi (1915 · Birinci Dünya Savaşı):** Dokuz aylık tarihi muharebe. Arıburnu'nda Mustafa Kemal veya İmroz'da Sir Ian Hamilton olarak komuta et.
- **Kan ve Demir (1862–71 · Berlin):** Otto von Bismarck olarak meclisi, sarayı ve beş büyük gücü idare et; Alman birliğini kur.
- **Tarafsızlık / Denge Politikası (1939–45 · Ankara):** İkinci Dünya Savaşı'nda Türkiye'nin tarafsızlığını koru; mihver ve müttefik dengesini yönet.
- **Açık Dünya (2026 · Orta Doğu):** 18 devlet, gerçek sınırlar, ordu, ekonomi, diplomasi, hava ve deniz harekâtı ile dinamik sandbox jeopolitik strateji.

## Çalıştırma

```bash
npm install
npm run dev
```

Uygulama `http://0.0.0.0:3000` adresinde sunulur. Üretim kopyası için:

```bash
npm run build
```
Çıktı `dist/` klasörüne yazılır.
